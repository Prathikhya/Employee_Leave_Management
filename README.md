
# Employee Leave Management System

A full-stack Employee Leave Management System developed using React.js and Spring Boot. The application helps organizations manage employee leave requests, authentication, role-based access, and leave approval workflows efficiently.

# Features
Employee Leave Application System
JWT Authentication & Authorization
Role-Based Access Control (Admin, Moderator, User)
User Registration & Login
Secure Spring Security Integration
Leave Request Management
Admin Dashboard
User Dashboard
Responsive Frontend UI
REST API Integration
Protected Routes
Form Validation
Session Handling using JWT Tokens
